
# NexVarejo

## Objetivo do projeto

O NexVarejo é um aplicativo desenvolvido para ajudar pequenos comerciantes a organizar seus produtos, registrar vendas e controlar o estoque.

## Funcionalidades principais

- Cadastro de produtos.
- Registro de vendas.
- Consulta de estoque.

## Tecnologia prevista

- Java
- Android Studio
- SQLite

## Público-alvo

Pequenos comerciantes que precisam de uma forma simples de organizar seus negócios.
